# A1 – Ansible Playbook (Lab 7.4.8)

## Doel
Automatisch installeren en configureren van een Apache webserver met Ansible.

## Werkwijze
- Ansible inventory aangemaakt met lokale webserver (192.0.2.3)
- Connectie getest met ping en command module
- Playbook gemaakt om Apache2 te installeren
- Apache automatisch gestart en getest via browser

## Playbooks
- test_apache_playbook.yaml : test communicatie
- install_apache_playbook.yaml : installatie Apache
- install_apache_options_playbook.yaml : Apache op poort 8081

## Test
Apache succesvol bereikbaar via:
- http://192.0.2.3
- http://192.0.2.3:8081
