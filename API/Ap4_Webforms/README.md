# Ap4 – Eigen API-experiment 2 (Python) – Webforms

## Doel
Een eenvoudige webapp maken met Python (Flask) en HTML webforms.

## Werking
- Een HTML formulier (index.html) stuurt data via POST
- Flask verwerkt de input
- Het resultaat wordt getoond op een nieuwe pagina (result.html)

## Bestanden
- app.py
- templates/index.html
- templates/result.html
